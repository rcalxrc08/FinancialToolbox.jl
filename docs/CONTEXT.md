# Documentation

The Documenter site, deployed by `DeployPage.yml` with GitHub Pages from Actions (no `gh-pages` branch).

## Inputs

| Load | Why |
|:--|:--|
| `make.jl` | pages (Guides and Reference), assets copied from `etc/` |
| `figures.jl` | figures computed at build time (light and dark SVG), `hero_figure`, `barrier_figure`, `hero_stats()` |
| `references/docs_design.md` | the shared design, what is static, the GPU calibration example, citations |
| `references/public_api.md` | every exported name is documented |
| `references/workflows.md` | how to build the docs locally |

## Process

- The design files are identical copies across the rcalxrc08 packages: edit them together.
- The performance table and the stat tiles are measured at build time; the GPU table of `gpu.md` is static (CI has no
  GPU), regenerated by `benchmark/gpu/run.jl`.
- Keep the deterministic 1% noise of the GPU calibration example (`references/docs_design.md`).
- In top-level loops of `@example` blocks update globals in place (Documenter's soft scope).

## Outputs

A site that builds with no warnings.
